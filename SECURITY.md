# Security Policy

## Supported versions

Qinari is in active development. Only the latest commit on `main` receives
security fixes.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Use GitHub's [private vulnerability reporting]
(https://github.com/AlbiFahriiza/qinari/security/advisories/new) to submit a
report with:

- A description of the issue and its impact
- Step-by-step reproduction instructions
- Any known workarounds

You will get an initial response within 7 days. We will keep you informed
about the fix and coordinate disclosure timing with you.

## Scope

In scope: anything shipped in this repository, including dependencies with a
known exploit reachable from this code. Out of scope: social engineering,
denial of service via obvious resource exhaustion, and issues in example
deployments you modified yourself.
